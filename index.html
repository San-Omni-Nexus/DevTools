Every developer needs good tools.

Most at times finding the right ones can be a challenge.

Here are some of the most useful ones with step by step instructions to set them up:

  • Python
  • VS Code
  • C++ Setup

1. PYTHON

Python is a beginner-friendly programming language with clear, readable syntax. It’s used for scripting, automation, data analysis, artificial intelligence and web backends. Many universities teach it first, and it pairs well with almost any other tool on this page.

Tap on the link below to download the latest python setup;

Python Download

Set-Up Instructions

1. Tap on Python download above.

2. Select Download Windows Installer (64 bit) under Stable releases, Python 3.14.10.

3. Open the downloaded file from your downloads.

4. Tick add to PATH.

5. Click on Install now.

6. Click Close when the installation is complete

7. To verify installation : Open command prompt by searching cmd in the windows search bar and press enter.

8. In cmd, type python --version and press Enter.

9. if you see the version number, 3.14.10, then python has been successfully installed on your device.

Setting Up Python in VS Code

1. Open VS Code and click on extension.

2. Search "python" in the search bar.

3. Download the extension published and verified by Microsoft. It is usually the first extension on the curated list.

2. Visual Studio Code

Visual Studio Code is a free, lightweight code editor that works with almost every language, including all the ones here. It colours your code, points out mistakes as you type and has a built-in terminal. Thousands of free extensions let you add support for C++, Python, JavaScript and more. Most beginners and professionals use it every day. Not to mention that, it is a recommended tool to use to write HTML and CSS instead of the primitive text editors.

Tap on the link below to download VS Code;

VS Code Download

Set-Up Instructions

1. Tap on VS Code Download above.

2. Locate and click Download for windows.

3. Wait for the download to finish.

4. Open the setup file from downloads.

5. Click 'Yes' when windows asks you to allow the setup to make changes to your PC.

6. Read the licese agreement and accept it. Click Next

7. Leave the default installation location, make no changes. Click Next.

8. Leave the default folder name, make no changes. Click Next.

9. Tick 'Create a desktop icon', 'Register Code as an editor for supported file types', and 'Add to PATH'.

10. CLick Next when finished.

11. Click Install and wait for installation to complete.

12. Click Finish.

3. C++ Setup

C++ is a powerful language used in systems software, games, embedded devices and telecoms. Unlike Python, your code must be compiled into a program before it can run, so you need a compiler installed. This setup gives you those tools, along with everything to write, build and run your first C++ programs. It’s a great way to learn how computers really work.

Tap on the link below to download MSYS2, a compiler for C++;

Download MSYS2

Set-Up Instructions

1. Tap on Download MSYS2.

2. Locate and install msys2-x86_64-20260927.exe.

3. Wait for it to finish downloading and run it from windows.

4. When it finishes, keep “Run MSYS2 now” ticked and click Finish, which opens an MSYS2 terminal.

5. In that terminal, run this command:

pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain

6. Press Y (then Enter) when it asks whether to continue. It will download and install for a few minutes.

7. Open Start Menu and, and search “Edit the system environment variables”.

8. Click Environment Variables, select Path under your user variables, then click Edit.

9. Keep the default install location

10. Click New and add the folder.

11. Click OK on every window to save.

12. Open VS Code and open extensions.

13. Search C/C++ and download the version provided and verified by Microsoft.
